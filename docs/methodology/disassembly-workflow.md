# Disassembly Workflow

1. Identify the target and record provenance.
2. Determine architecture, container/file format, and memory layout.
3. Produce an initial disassembly without assigning unsupported semantics.
4. Separate code, data, tables, text, graphics, and unknown regions.
5. Introduce stable symbols and naming conventions as evidence improves.
6. Reconstruct source organization incrementally.
7. Compare outputs and behavior using reproducible checks.
8. Record unresolved regions and verification status.
