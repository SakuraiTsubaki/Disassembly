# Roadmap

## Foundation — complete

- repository boundaries and evidence method;
- project catalog and JSON schemas;
- hashing and validation tools;
- tests, continuous integration, and contribution templates.

## Baseline identification

- verify retail release and revision matrices;
- record legal metadata and hashes only;
- establish per-target address conventions and toolchain candidates.

## Structural analysis

- produce bank or section maps;
- classify code, data, text, graphics, scripts, maps, and audio;
- publish confidence and provenance for every range.

## Reconstruction readiness

- pin toolchains;
- define reproducibility gates;
- begin source reconstruction only where evidence is sufficient.
